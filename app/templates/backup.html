  3. Renomeie para anatel.db e substitua o arquivo em {{ banco.parent }}.
  4. Abra o sistema de novo.

Atualizações do sistema não apagam dados

Quando o sistema ganha um campo novo, ele compara o banco com o modelo atual e acrescenta o que falta — tabelas e colunas novas. Nada é recriado e nada é apagado:

  • antes de qualquer mudança de estrutura, uma cópia automática é gerada;
  • colunas que saíram do sistema continuam no banco, apenas ignoradas;
  • os dados iniciais (OCDs, vistas, modelos de documento) só são inseridos quando a tabela está vazia — suas edições nunca são sobrescritas.
